# NEXAHEDRON Phase I Implementation Baseline

- Status: Accepted implementation baseline
- Phase: I
- Architecture: frozen NEXAH Framework and ORION v1
- Laboratory role: independent application boundary

NEXAHEDRON owns only the Laboratory experience, user interface, session flow,
interaction, visualization, Atlas exploration and report presentation.

It must never become a second NEXAH or a second ORION. It does not own planning,
validation, canonical truth, LYRA translation, Library editorial effects or
Human Reflection and decision.

## Product language

The primary interface uses Orientation Workspace, Orientation Laboratory,
Living Atlas and Orientation Report. It does not present itself as an assistant,
chat interface, conversation surface or search engine.

## Phase I implementation rule

A visual control is implemented only when it maps to an approved capability and
an authoritative structured field. Future blueprint capabilities remain absent
or explicitly unavailable; they are never simulated as complete.

## Milestone discipline

Each milestone is independently reviewed. Work stops after the milestone report
and does not continue until review approval.
