# Editorial Strategy for the Orientation Library

- Status: Canonical editorial constitution
- Scope: selection, development, review and stewardship of Orientation Cases
- Time horizon: long-term
- Product implementation: out of scope

The Orientation Library should grow by editorial intent.

It should not follow search volume, news cycles, contributor enthusiasm or a
desire to appear comprehensive. Each new case should strengthen the landscape:
it should establish a foundation, close an important gap, create a meaningful
bridge or make a difficult uncertainty easier to inspect.

## Editorial purpose

The Library exists to help people find their bearings across subjects and
sources.

Editorial work therefore asks:

- Which orientation would make many later orientations possible?
- Which important relationship is currently difficult to see?
- Which evidence can be inspected faithfully?
- Which uncertainty needs clearer boundaries?
- Which domain or perspective is missing from the landscape?
- Which continuation would become possible if this case existed?

The aim is not to publish everything. It is to create a coherent public path
through what matters.

## What should be created first

The earliest cases should combine six qualities.

### Foundational leverage

Prefer subjects that help readers enter many later cases.

A case about evidence, scale, energy, maps, proof, evolution or feedback can
support orientation across multiple fields. A highly specialized case may be
excellent, but it should not displace the foundations needed to use it.

### Inspectable evidence

Prefer cases with public, identifiable and stable sources. Early cases should
teach readers that claims can be traced and that evidence has limits.

When evidence is restricted, unstable or deeply contested, the editorial burden
is higher. Such a case may still matter, but it is rarely the best first case in
a collection.

### Durable questions

Prefer questions that remain useful beyond a news cycle:

- What is a scientific model?
- How does a map represent space?
- What does an algorithm do?
- How does natural selection relate to evolution?
- What is conserved when energy changes form?

Durability does not require timeless certainty. It requires a question whose
orientation remains meaningful as evidence develops.

### Familiar entry, deeper structure

Early cases should often begin with something recognizable while revealing
relationships that are not obvious.

Plate tectonics is a useful example: many people have heard that plates move,
but fewer can connect motion, boundary type, geological process, evidence and
prediction limits.

### Bridge value

Prefer cases that create honest paths between collections.

A case about geological time can connect Earth, Time, Maps and Learning. A case
about networks can connect Computing, Systems, Life and Human Society. Every
bridge must preserve the differences between the domains it connects.

### Reviewability

Prefer subjects for which the editorial team can assemble appropriate review.

A case should not be published simply because it can be written. The Library
must be able to review its evidence, boundaries, language and meaningful
uncertainty.

## Selection order

Editorial selection should normally proceed in this order:

1. correct or withdraw a materially misleading existing case;
2. complete missing foundations required by published cases;
3. strengthen weak evidence, uncertainty or boundary coverage;
4. create continuations that make existing cases more useful;
5. establish an underrepresented collection or perspective;
6. add a cross-disciplinary bridge;
7. add an advanced or specialized case;
8. respond to current public attention only when it reveals a durable need.

This order is a guide, not an automatic score. Editorial judgment remains
explicit and reviewable.

## Balance between domains

Balance does not mean publishing the same number of cases in every category.

A balanced Library lets visitors enter through different kinds of knowledge
and encounter different kinds of evidence, scale, time and uncertainty. It
should not quietly define “knowledge” as only the subjects most familiar to its
maintainers.

Editors should review the landscape across several dimensions:

| Dimension | Questions for review |
|---|---|
| domain | Are science, mathematics, technology, humanities, arts and society all visible? |
| evidence | Do cases include observation, experiment, measurement, documents, artifacts, testimony, derivation and maps where appropriate? |
| scale | Can visitors orient from personal and local scales to planetary and abstract scales? |
| time | Are short processes, historical change, deep time and timeless relations represented? |
| geography | Does the Library overrepresent one region or institution? |
| perspective | Are disagreements and different methods visible without false balance? |
| difficulty | Are there genuine entry cases as well as deeper continuations? |
| connection | Do collections speak to one another, or have they become isolated shelves? |
| uncertainty | Are some domains presented as falsely settled while others carry all visible doubt? |
| audience | Can teachers, students, researchers, builders and curious visitors each find a responsible entry? |

Review these dimensions periodically and publish the identified gaps. Do not
turn them into mechanical quotas. A count can reveal imbalance; it cannot decide
which case deserves publication.

## Foundational and advanced cases

### Foundational cases

A foundational case establishes orientation that can be reused.

It should:

- begin with little assumed vocabulary;
- define one durable subject or relationship;
- make its evidence type understandable;
- show the limits of its simplified account;
- create several useful continuations;
- connect to more than one later case where appropriate;
- remain valuable to an advanced reader who needs to inspect the foundation.

Foundational does not mean simplistic, certain or written only for children. It
means structurally prior.

### Advanced cases

An advanced case asks for existing orientation and goes further into a bounded
problem.

It may:

- use specialized vocabulary;
- depend on prerequisite cases;
- inspect narrower or more technical evidence;
- compare competing models;
- preserve unresolved professional disagreement;
- require mathematical, historical or methodological preparation;
- offer continuations into primary research.

An advanced case should name its prerequisites and explain why they matter. It
must not hide behind complexity or treat specialist language as authority.

### Relationship between them

Advanced cases should deepen the landscape rather than replace foundations.
Foundational cases should remain stable enough to support later work while being
correctable when their evidence or framing changes.

## When to create a new case

Create a new case when one or more of the following are true:

- the Human intention is materially different;
- the subject requires a distinct scope;
- the evidence belongs to a different authority or method;
- the case needs a different starting orientation;
- an alternative perspective deserves independent treatment;
- the depth would make the existing case unusable for its intended reader;
- the new material creates its own unknowns and continuations;
- the relationship between the two subjects is itself important to inspect;
- the existing case would become an unbounded article if expanded.

Examples:

- “What is plate tectonics?” and “How is earthquake hazard assessed in one
  region?” should be separate cases.
- “What is a mathematical proof?” and “How does proof by induction work?” may
  form a foundation and continuation.
- Different historical interpretations may require separate perspective cases
  when combining them would blur their evidence and assumptions.

## When to expand an existing case

Expand or correct an existing case when:

- the Human intention and scope remain the same;
- a source version changes without changing the orientation's subject;
- evidence, counterevidence or provenance was missing;
- an assumption or boundary needs to become explicit;
- a relationship needs clearer explanation;
- a continuation link becomes available;
- the case can improve without becoming harder to enter;
- the change corrects an error while preserving the case's purpose.

Material revisions should remain traceable. Expansion must not turn a bounded
case into a general article.

## Foundational Collections

Collections are editorial paths through cases. They are not isolated domains,
and a case may contribute to more than one collection.

### Foundations of Science

#### Why it exists

People encounter scientific claims long before they learn how observation,
measurement, models, experiments, uncertainty and revision relate.

#### Which cases belong

Cases may orient around observation, measurement, hypothesis, model, theory,
experiment, replication, causation, correlation, uncertainty, peer review and
the changing status of evidence.

#### What orientation it develops

The reader learns to distinguish data from interpretation, confidence from
certainty and a useful model from final truth.

### Foundations of Mathematics

#### Why it exists

Mathematics is often presented as a collection of procedures rather than a way
of relating definitions, structures, representations and proof.

#### Which cases belong

Cases may orient around number, equality, function, proof, geometry, ratio,
probability, infinity, symmetry, approximation and mathematical modeling.

#### What orientation it develops

The reader learns how mathematical objects are defined, how conclusions follow
and how representations reveal different aspects of the same structure.

### Foundations of Computing

#### Why it exists

Digital systems shape daily life while their layers and limitations often
remain hidden.

#### Which cases belong

Cases may orient around data, algorithm, program, abstraction, state,
computation, network, database, interface, security and the distinction between
software behavior and Human purpose.

#### What orientation it develops

The reader learns to see how instructions, representations, systems and people
relate without treating computation as explanation by itself.

### Earth

#### Why it exists

Earth processes connect land, oceans, atmosphere, life and deep time. They are
often learned as separate topics.

#### Which cases belong

Cases may orient around plate tectonics, rocks, soils, oceans, atmosphere,
water cycle, weather, climate, erosion, earthquakes, volcanoes and geological
time.

#### What orientation it develops

The reader learns to move between process, place, scale, evidence and hazard
without confusing explanation with prediction.

### Life

#### Why it exists

Living systems operate across molecular, cellular, organismal, ecological and
evolutionary scales.

#### Which cases belong

Cases may orient around cell, metabolism, inheritance, variation, natural
selection, evolution, development, organism, ecosystem and biological
classification.

#### What orientation it develops

The reader learns how levels of life relate, how evidence supports biological
explanations and where simplified purpose-language can mislead.

### Energy

#### Why it exists

Energy connects physics, chemistry, life, Earth systems, technology and public
decisions, yet the word changes meaning in everyday speech.

#### Which cases belong

Cases may orient around energy, work, heat, conservation, transformation,
electricity, chemical energy, metabolism, fuels and energy systems.

#### What orientation it develops

The reader learns what is conserved, what changes form, where losses matter and
how physical description differs from social choice.

### Language

#### Why it exists

Language carries meaning, identity, culture and knowledge, but no word has the
same role in every context.

#### Which cases belong

Cases may orient around speech, writing, grammar, meaning, context,
translation, metaphor, language change, multilingualism and signs.

#### What orientation it develops

The reader learns to notice how form, meaning, use and context interact—and why
translation must preserve differences rather than erase them.

### Time

#### Why it exists

Time is measured, experienced and represented differently across physics,
history, geology, biology and daily life.

#### Which cases belong

Cases may orient around sequence, duration, calendar, clock, historical period,
deep time, rate, cycle, simultaneity and temporal evidence.

#### What orientation it develops

The reader learns to distinguish event, record, measurement, scale and
interpretation across time.

### Maps

#### Why it exists

Maps make relationships visible by selecting and transforming space. Their
clarity can hide those choices.

#### Which cases belong

Cases may orient around scale, projection, coordinate, boundary, layer,
legend, territory, uncertainty, thematic mapping and spatial data.

#### What orientation it develops

The reader learns to inspect what a map represents, omits, distorts and makes
possible.

### Systems

#### Why it exists

Many important subjects cannot be understood by examining their parts in
isolation.

#### Which cases belong

Cases may orient around system, boundary, feedback, network, emergence,
equilibrium, resilience, flow, dependency, adaptation and failure.

#### What orientation it develops

The reader learns to see interactions across scale while resisting the idea
that every similarity proves the same mechanism.

### Human Society

#### Why it exists

Institutions, economies, laws, cultures and collective histories shape Human
life through contested meanings and unequal effects.

#### Which cases belong

Cases may orient around institution, governance, law, economy, culture, power,
population, public goods, collective action, rights and social change.

#### What orientation it develops

The reader learns to distinguish description, interpretation, value judgment
and lived perspective while inspecting sources and disagreement.

### Learning

#### Why it exists

Learning is often measured by completion or recall even when understanding,
transfer and uncertainty matter more.

#### Which cases belong

Cases may orient around attention, memory, practice, misconception,
explanation, feedback, assessment, inquiry, transfer and teaching.

#### What orientation it develops

The reader learns how knowledge changes through use, correction and reflection
without reducing every learner to one method.

## Relationships among collections

Collections should form a connected landscape.

Examples of durable bridges include:

- Science ↔ Mathematics through measurement and modeling;
- Earth ↔ Time through geological records;
- Life ↔ Energy through metabolism;
- Computing ↔ Language through representation;
- Maps ↔ Human Society through boundaries and power;
- Systems ↔ Ecology through feedback and resilience;
- Learning ↔ Language through explanation and translation;
- Mathematics ↔ Music through ratio, pattern and time.

Each bridge should eventually be demonstrated by actual cases. A named bridge
without reviewed cases remains an editorial intention, not a published
connection.

## Case maturity

Maturity describes editorial status, not truth or importance.

### Draft

A Draft is being developed.

- its structure or evidence may be incomplete;
- it has not passed independent editorial review;
- claims and connections may change;
- it must not be presented as a current public orientation;
- feedback should focus on missing evidence, boundaries and clarity.

### Reviewed

A Reviewed case has received appropriate independent review.

- the canonical structure is complete;
- sources and major claims have been inspected;
- assumptions, uncertainty and boundaries are visible;
- requested corrections have been addressed or preserved as disagreement;
- it may be published with its reviewed status and limitations;
- further domain or community review may still be needed.

### Canonical

A Canonical case is the current preferred public orientation for its declared
intention and scope.

- evidence and editorial review are sufficient for the stated use;
- identity and version are stable;
- relationships and continuations have been reviewed;
- significant known disagreement is represented;
- corrections create a traceable new version;
- canonical does not mean final, complete or universally authoritative.

### Historical

A Historical case is preserved because it records an earlier orientation,
source state, interpretation or editorial decision.

- it is no longer the current preferred case;
- its original identity and content remain inspectable;
- the reason and date of replacement are visible;
- links point to the current case when one exists;
- it may remain valuable for research, teaching or comparison.

### Archived

An Archived case is removed from normal discovery but retained when permitted.

Reasons may include:

- evidence can no longer be resolved;
- the case materially violates current standards;
- authority or permission was withdrawn;
- the scope is duplicated by a better governed case;
- continued public navigation would mislead.

Archiving is not silent deletion. The reason, status and successor should remain
visible where legally and ethically possible.

## Maturity transitions

```text
Draft
→ Reviewed
→ Canonical
→ Historical
→ Archived when necessary
```

Not every case must become Canonical. A Reviewed case may remain the appropriate
status when perspectives are developing or evidence is limited. A Canonical
case may return to Reviewed during substantial revision. A case may be Archived
from any published state when harm, authority or evidence requires it.

Status changes require a recorded reason and responsible review. Popularity
does not promote maturity.

## Community proposals

Community proposals should be welcomed through a transparent editorial queue.

A useful proposal includes:

- proposed title;
- Human intention;
- collection or bridge it strengthens;
- likely starting orientation;
- initial public sources;
- known uncertainty or dispute;
- expected prerequisites and continuations;
- contributor and reviewer capability;
- reason the case should exist separately.

## Prioritizing proposals

Review proposals against these questions:

1. **Need** — Does it close a visible orientation gap?
2. **Foundation** — Will it support several later cases?
3. **Evidence readiness** — Can its major claims be inspected responsibly?
4. **Durability** — Will the intention remain useful beyond current attention?
5. **Bridge value** — Does it connect collections or perspectives meaningfully?
6. **Balance** — Does it correct a domain, evidence, geographic or difficulty
   imbalance?
7. **Review capacity** — Can suitable reviewers assess it?
8. **Maintenance** — Can the case and its sources be stewarded over time?
9. **Risk** — Could weak evidence or unclear authority cause material harm?
10. **Scope** — Is it small enough to orient well?

Priority should not be determined by votes, followers, search traffic or the
prominence of the proposer.

Strong proposals may still wait when foundations or review capacity are
missing. The reason for deferral should be visible.

## Current events and news

Avoid news-driven publishing.

When an event creates public attention, ask whether the Library lacks a durable
orientation needed to understand it. Often the right response is a foundational
case about the underlying process, institution, evidence type or historical
context—not a rapidly assembled page about the event.

Create an event-specific case only when:

- the event has durable orientation value;
- sufficient evidence and context can be inspected;
- uncertainty is represented honestly;
- appropriate review is available;
- the case will remain useful after immediate attention fades.

The Library should be comfortable being slower than the news.

## Editorial principles

### Prefer timeless cases

Choose subjects and intentions that remain useful. Update evidence when needed
without making constant novelty the organizing principle.

### Prefer foundational ideas

Build the concepts, relationships and methods that allow later depth.

### Prefer inspectable evidence

A bounded case with traceable sources is stronger than a comprehensive-looking
case built on uninspectable claims.

### Prefer reusable orientation

Create cases that can support learning, comparison and continuation in several
contexts without becoming vague.

### Prefer depth over quantity

Do not publish a weak case to fill a category. A visible gap is more honest and
more useful than false completeness.

### Prefer connection over isolation

Every case should strengthen a path, collection or bridge. Connections must be
explained and reviewed.

### Prefer uncertainty over premature closure

Disagreement and unknowns belong in the Library. Editorial polish must not make
them disappear.

### Prefer correction with history

Revise errors and preserve what changed. Do not silently rewrite the Library's
past understanding.

### Avoid quantity targets

Counts can describe the Library. They must not determine editorial quality or
publication timing.

## The First 100 Cases

The phrase “first 100” describes a review horizon, not a production quota.

An ideal first public Library would feel like a balanced landscape rather than
a partial encyclopedia.

### It would have multiple entrances

A visitor could begin with a scientific question, a map, a mathematical
relationship, a historical change, a work of language or a system in everyday
life. No single discipline would define the meaning of Orientation.

### It would establish every foundational collection

Each collection would have enough cases to create a coherent entry and at least
one meaningful continuation. Some collections would be deeper than others
because evidence and review capacity differ, but none would exist as an empty
label.

### It would contain foundations and depth

Most cases would establish reusable orientation. A smaller group of advanced
cases would demonstrate how the same structure supports specialist evidence,
disagreement and technical detail.

### It would show several kinds of evidence

Visitors would encounter measurement, experiment, document, map, artifact,
testimony, dataset and mathematical derivation in contexts where each is
appropriate. They would learn that evidence standards differ without becoming
arbitrary.

### It would cross domains carefully

The landscape would contain strong bridges around scale, time, energy,
language, systems, maps and patterns. Each bridge would preserve where the
analogy or shared concept stops.

### It would include disagreement and limits

Some cases would orient around contested interpretations. Others would show
where a successful model stops working. Unknowns would be visible as frontiers,
not postponed content.

### It would span scales and perspectives

The Library would move from cells to ecosystems, numbers to networks, personal
learning to institutions, moments to deep time and local maps to planetary
systems. It would not treat one region, language or institution as the default
view of the world.

### It would form usable paths

A visitor could follow short sequences:

- an entry case;
- a deeper concept;
- an evidence case;
- a contrasting perspective;
- a continuation into another collection.

The value of the first 100 would be the quality of these paths, not the number
100 itself.

### It would remain maintainable

Every published case would have review evidence, known limitations and a
realistic stewarding path. The Library would not grow beyond its ability to
correct and explain what it has published.

## Editorial review of the landscape

At regular intervals, editors should review the Library as a whole.

Ask:

- Which cases are most useful as foundations?
- Where do visitors reach dead ends?
- Which collections are isolated?
- Which evidence types or regions are overrepresented?
- Which cases require correction, deeper review or archival?
- Which unknowns deserve a case, and which should remain explicit frontiers?
- Are advanced cases accumulating before their foundations?
- Are community proposals broadening the landscape or following attention?
- Can the editorial team still maintain what it has published?

Publish the resulting priorities and deferrals. Editorial intent should be
visible enough to review.

## Long-term vision

The Orientation Library should grow like a carefully curated museum, not like
an endless feed.

A museum does not display every object it can obtain. It chooses, relates,
interprets, preserves and revises. It creates rooms with purpose. It leaves
space around important things. It records provenance. It changes exhibitions
without pretending the past did not exist.

The Library should do the same with Orientation Cases.

Over years, its strength should come from:

- durable foundations;
- careful evidence;
- meaningful bridges;
- visible uncertainty;
- diverse forms of knowledge;
- traceable correction;
- patient editorial stewardship.

The Library should never need to become endless to become useful.
